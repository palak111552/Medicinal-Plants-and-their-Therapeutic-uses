#Medicinal-Plants-and-their-Therapeutic-uses
A data analysis project exploring medicinal plants and their therapeutic properties using Python. The project focuses on cleaning, processing, and analyzing a structured dataset to generate insights into medicinal attributes and healthcare significance.

 #Key Highlights

Data cleaning and preprocessing

Handling missing values

Exploratory Data Analysis (EDA)

Data visualization using matplotlib and seaborn

Insight generation from structured herbal medicine data

#Tech Stack

Python

pandas

matplotlib

seaborn

Jupyter Notebook

#Goal

To demonstrate practical data analysis skills by transforming raw medicinal plant data into meaningful visual and analytical insights.
